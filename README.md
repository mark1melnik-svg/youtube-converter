# YouTube Converter

**YouTube Converter** — современное портативное приложение для Windows, разработанное для удобного скачивания видео, аудио и субтитров с YouTube.

---

## ✨ Ключевые возможности

* **Гибкие форматы:** скачивание видео (MP4, WebM) и конвертация аудио (MP3, M4A, Opus) с выбором качества.
* **✂️ Точная обрезка по таймкодам:** загрузка только выбранного фрагмента видео или аудио (форматы `00:00:00` или `01:30`) без скачивания файла целиком.
* **📋 Очередь загрузок:** пакетное скачивание списков ссылок, сохранение и загрузка очередей из текстовых файлов.
* **⚡ Аппаратное ускорение:** поддержка ускорения через FFmpeg с использованием NVIDIA NVENC, Intel QuickSync (QSV) и AMD AMF.
* **Вшивание метаданных:** добавление обложки ролика и ID3-тегов прямо в аудиофайлы.
* **Только субтитры:** отдельный режим выгрузки субтитров в формате `.srt` (включая автоматические субтитры).
* **Удобный интерфейс:** поддержка светлой и тёмной тем оформления, авто-вставка ссылок из буфера обмена, превью роликов, история загрузок и два языка интерфейса (русский и английский).
* **Автономная работа:** встроенная проверка рабочего окружения (`yt-dlp`, `ffmpeg`, `Node.js`) без необходимости ручной установки зависимостей в систему.

## 🍪 Решение проблем со скачиванием (HTTP 403 / Bot-Check)

Если YouTube запрашивает проверку на бота или прерывает загрузку с ошибкой, используйте авторизацию через cookies:

1. Установите расширение для браузера для экспорта cookies (например, *Get cookies.txt LOCALLY*).
2. Авторизуйтесь на сайте YouTube в браузере.
3. Экспортируйте файл куков под именем `cookies.txt`.
4. Укажите путь к файлу в **Настройках** программы либо положите `cookies.txt` в папку рядом с `yt_converter.exe`.

---

## 🚀 Установка и запуск

1. Перейдите в раздел **[Releases](https://github.com/mark1melnik-svg/youtube-converter/releases)** и скачайте архив `yt_converter.zip` актуальной версии.
2. Распакуйте архив в любую удобную папку на компьютере.
3. Запустите исполняемый файл `yt_converter.exe` (установка Python не требуется).
