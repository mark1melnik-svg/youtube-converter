# YouTube Converter

**YouTube Converter** — это простое приложение на русском языке для Windows, разработанное для удобного скачивания видео, аудио и субтитров с YouTube.

## ✨ Особенности
* **Гибкие форматы:** Скачивание видео (MP4) и аудио (MP3) с автоматическим выбором доступного качества.
* **Только субтитры:** Отдельный режим выгрузки субтитров в формате \SRT\ (удобно для быстрого получения текста без скачивания тяжелых файлов).
* **Автономная работа:** Приложение имеет встроенную систему проверки окружения и использует локальные утилиты \yt-dlp\, \fmpeg\ и \Node.js\ для стабильного декодирования скриптов YouTube.

## 🍪 Решение проблем со скачиванием (HTTP Error 403 / Блокировки)
YouTube активно борется с автоматическими запросами. Если у вас появляется ошибка скачивания, приложению необходимы файлы авторизации (cookies).

### Как настроить cookies:
1. Установите в свой браузер расширение для экспорта куков (например, *Get cookies.txt LOCALLY* или *cookie.txt*).
2. Зайдите на сайт YouTube под своим аккаунтом.
3. Откройте расширение и скачайте файл куков для YouTube.
4. Назовите скачанный файл **\cookies.txt\** и положите его в корневую папку рядом с исполняемым файлом программы.
5. Перезапустите приложение — оно автоматически подхватит куки для обхода блокировок.

## 🚀 Установка и запуск
1. Перейдите в раздел **Releases** на панели справа и скачайте архив последней версии (\1.0.1\).
2. Распакуйте архив в любую удобную папку на компьютере.
3. Запустите исполняемый файл \yt_converter.exe\.
